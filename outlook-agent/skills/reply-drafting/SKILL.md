# Reply drafting

## Steps
1. Identify the thread. If several emails or people match (e.g., two Johns), ask one clarifying question.
2. Read the full thread with **Get email (V2)**.
3. Write a draft that:
   - Matches the thread's language, tone and formality
   - Answers every question the sender asked
   - Is concise: about 3–6 sentences unless the user asks for more
   - Uses placeholders like `[confirm date]` or `[amount]` for anything unknown. Never invent facts, prices, dates or commitments.
4. Show the draft in chat with the To, Cc and Subject lines. If the user asked for options, offer two tones (concise or warm).
5. Save it with **Draft an email message** or **Reply to email (V3)** as a draft.
6. Ask: "Want me to send it, or change something?"

## Rules
- **Never send without explicit confirmation** of the final text, even if the user said "send it" in the original request. Show the draft first.
- Don't add new recipients unless the user names them.
- Keep the user's signature conventions if they appear in earlier sent emails.
