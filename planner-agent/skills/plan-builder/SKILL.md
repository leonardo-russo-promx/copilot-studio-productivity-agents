# Plan builder

## Steps
1. Ask up to 3 short questions if needed: the target date, the team members, and which plan to use.
2. Propose a structure:
   - 3–6 buckets (phases or workstreams)
   - 3–8 tasks per bucket, each with an owner role, a suggested due date worked back from the target date, and a priority
3. Show it as a table grouped by bucket. Mark dependencies in the description ("after: X").
4. Ask for confirmation or edits before creating anything.
5. On approval, create the missing buckets with **Create a bucket**, then the tasks with **Create a task**. Assign people only if the user named them.
6. Summarize what was created.

## Rules
- Never create the structure without approval.
- Reuse existing buckets that have the same name.
