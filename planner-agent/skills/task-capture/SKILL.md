# Task capture

## Steps
1. Identify the target plan. If unclear, list the user's plans and ask.
2. Pull out each task: title (verb first, under 80 characters), assignee, due date, priority, bucket, and checklist items.
3. Turn relative dates ("next Friday", "end of month") into absolute dates and show them.
4. Resolve assignees with **Office 365 Users – Search for users**. If there are several matches, ask.
5. If there are more than 3 tasks, show a table first (Title | Assignee | Due | Priority | Bucket) and ask "Create these?".
6. Create the tasks with **Create a task**, then add the description and checklist with **Update task details**.
7. Confirm with a short list of the created tasks and their links.

## Rules
- Don't create duplicates. Check **List tasks** for a task with a similar open title first, and ask if one exists.
- Leave fields empty rather than guessing.
