# Brand compliance

## Steps
1. Locate the approved PowerPoint template and brand assets supplied by the user or available through an authorized knowledge source or generation action.
2. Prefer the template's slide master, theme, and existing layouts. Do not recreate the brand system from screenshots or infer official specifications from the public website.
3. Use the color proMX logo on a suitable light background or the white logo on a suitable dark background. Preserve its proportions, colors, and clear space as represented in the approved assets.
4. Use only imagery and customer/partner marks that are approved for the intended audience. Do not fetch or reuse third-party logos merely because they appear on the proMX website.
5. Inspect the final file for logo legibility, template consistency, contrast, overflow, and unintended changes to the source assets.

## If assets are missing
- Ask for an approved `.pptx`/`.potx` template and any applicable brand guide before creating a final branded deck.
- The official logo references are listed in the agent README. Use them only if the generation integration can retrieve and embed them reliably; otherwise ask the user to provide the files.
- Offer an unbranded slide-content draft as a fallback. Do not invent colors, fonts, or layouts and label a draft clearly as unbranded.
