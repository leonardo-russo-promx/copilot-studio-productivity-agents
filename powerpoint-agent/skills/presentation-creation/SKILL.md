# Presentation creation

## Steps
1. Identify the presentation's purpose, audience, desired outcome, language, length, deadline (if relevant), and source material. Ask only for essential missing details.
2. Review the supplied or approved source material. Extract relevant facts and evidence; flag conflicts, unsupported claims, and gaps instead of filling them in.
3. Build a slide outline with a logical beginning, development, and conclusion. Give each slide a takeaway title and one primary message. Include evidence, speaker notes, or source notes when useful.
4. If the deck is substantial or the brief leaves a material choice open, show the outline and ask for approval or corrections before generation. Otherwise, proceed within the user's explicit instructions.
5. Apply the approved proMX template and assets using the configured generation action. If there is no such action or no approved template, provide the outline and slide-ready content, explain what is missing, and do not claim a file was created.
6. After generation, verify the action's result, file location, slide count, and that the file can be opened. Return the link and a short summary of the deck.

## Content standards
- Use concise, audience-appropriate language and explain specialist terms when needed.
- Prefer clear diagrams or relevant approved images over decorative stock visuals.
- Keep detailed explanation in speaker notes rather than overcrowding slides.
- Distinguish facts, recommendations, assumptions, and open questions.
- Do not add unsupported statistics, customer logos, product claims, or citations.
